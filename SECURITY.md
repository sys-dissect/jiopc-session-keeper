# Security Policy

## Reporting Security Vulnerabilities

We take privacy, data protection, and security seriously. 

If you discover a potential vulnerability, bug that exposes personal data, or security issue:

1. **Do not create a public GitHub issue.**
2. Instead, use GitHub's private security advisories feature:
   - Go to the **Security** tab of the repository.
   - Click **Report a vulnerability**.
3. Include details of the vulnerability, reproduction steps, and potential impact.

## Privacy & Redaction Guidelines
Contributors are strictly requested to ensure no Personally Identifiable Information (PII), proprietary internal vendor names, private IP addresses, or authentication tokens are submitted in PRs or issues.
